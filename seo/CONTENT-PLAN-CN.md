## 三、P0 —— 地域 × 服务矩阵(最大缺口,建议优先)

关键词库里 `地域-年审词 / 审计词 / 开户词 / 税务词` 共 36 条,目前仅 6 条有正文覆盖。
这类词搜索意图明确、竞争度低、转化路径短,是大陆搜索流量最容易拿的一块。

建议新增两个页面族(每页可复用现有数据字段,不必从零创作):

1. **`/{国家}-annual-review` 年审页族**
   覆盖:新加坡年审、香港公司年审、美国公司年审、马来西亚年审、开曼年审、
   英国年审、日本年审、迪拜年审、印尼年审、泰国公司年审
   数据源:`data-countries.js` 的 `regulator / period` + `services/annual-review` 已有内容

2. **`/{国家}-audit` 与 `/{国家}-tax` 页族**
   覆盖:新加坡公司审计、美国公司审计、泰国公司审计、印尼审计、
   新加坡 GST 注册、美国联邦税、马来西亚税务、泰国 VAT、香港利得税

> 说明:这两族页面必须来自真实业务口径(年审费用区间、审计触发条件、税率),
> 数据源不全的项先留空,不要先上线占位页 —— 薄内容会拉低整站质量分。

## 七、如何复跑

```bash
# 1) 关键词覆盖率(输出 CSV + 控制台摘要;默认读 Obsidian 关键词库)
node scripts/seo-cn-coverage.js
#   可选: --keywords <path>  --out <csv>  --type GEO问句

# 2) 补齐国家页问句化问答(幂等)
node scripts/inject-country-qa.js

# 3) 重跑大陆市场适配注入(meta / Organization / 速答)
node scripts/inject-cn-seo.js

# 4) 刷新 llms.txt 事实层
node scripts/inject-llms-facts.js
```

执行顺序不能颠倒:`inject-country-qa` 会新增 FAQ,`inject-cn-seo` 的速答块按
「与 H1 最相关的 FAQ」重选,`inject-llms-facts` 再从页面抽取问答原文。

三个注入脚本都是幂等的:连续执行第二次必须全部报 0 变更。
如果报非 0,说明锚点文本被改动过,先 `git diff` 看清再跑。
