商标被驳回、被抢注:复审、异议与备用方案

驳回分两种:一种是标识本身有问题,一种是撞上了在先商标。前者靠改,后者靠打或靠谈。被抢注则要同时准备"夺回"和"先上市"两条线。

速答

商标驳回要先分清原因:标识缺乏显著性、违反禁用条款属于绝对理由,通常只能修改标识重新申请;与在先商标近似属于相对理由,可以通过驳回复审、删除冲突类别、取得共存同意或对在先商标提出撤三来解决。被抢注时,一边走异议/无效程序,一边准备可替代的备用标识先上市,避免错过销售档期。

一、先分清驳回理由

类型常见情形应对
绝对理由缺乏显著性、描述性、通用名称、违反禁用条款修改标识或增加显著图形,重新申请
相对理由与在先商标相同或近似驳回复审、删减类别、共存同意、对在先商标撤三
程序问题类别选择不当、材料不规范补正或重新提交,通常不影响实体判断

判断标准是"整体是否容易导致混淆",不是逐字比对。文字近似但图形差异明显、或类别不类似,都有争辩空间。

二、驳回复审怎么做

  1. 调取驳回通知书,确认引证商标与引用的具体条款
  2. 评估引证商标状态(是否有效、是否可撤三、是否可协商)
  3. 确定策略:纯论证、删减商品/类别、共存同意,或组合使用
  4. 在法定期限内提交复审理由与证据(使用证据、知名度、市场区分)
  5. 同步准备备用方案:调整标识,避免复审失败后完全空档

时间:复审通常需要 9–12 个月,异议与无效程序更长。进入新市场前先做检索,比事后打程序便宜得多。

三、被抢注:两条线同时走

  • 法律线:对抢注商标提出异议、无效宣告或撤三(连续三年不使用)
  • 商业线:准备可替代的备用标识,先把产品与包装上市,避免整季空档
  • 谈判线:评估转让或许可的成本,有时比程序更快
  • 防御线:核心类别 + 关联类别 + 目标市场同步布局

抢注者往往赌的是"你等不起"。先解决能不能卖,再解决商标归谁,顺序反了会错过市场窗口。

四、三个脱敏案例

欧盟 · 消费品牌
核心品类被抢注,异议与备用标同步走
情形:进入欧洲市场时发现核心品类已被他人抢注,新品无法合规上架,重新设计包装又赶不上档期。
处理:先做检索锁定抢注主体与类别,同步启动异议或无效程序,并准备可替代的备用标识先行上市。
结果:争议程序推进期间用备用标完成上架;最终收回核心类别,避免了整季空档。
提示:进入新市场前先做商标检索,成本远低于被抢注后的争议与改包装。
美国 · 电商
描述性词汇被驳回,改用臆造组合
情形:申请名称由行业通用词组成,被认定缺乏显著性而驳回,申请费不退。
处理:改为臆造词与图形组合重新申请,同时保留原标识作为包装说明使用。
结果:新申请核准注册;原方案改为辅助标识,不影响店铺运营。
提示:越"说明产品是什么"的名字越难注册;臆造词、任意词的显著性最强。
马德里 · 多国
基础申请被撤,转逐国申请保住市场
情形:通过马德里体系延伸多国,但基础申请在五年内被撤销,导致国际注册一并失效。
处理:评估受影响国家,把核心市场转为逐国直接申请,并保留优先权衔接。
结果:核心市场重新获得保护,非核心国家按销售计划分批补申。
提示:马德里体系依附基础申请五年;基础不稳时,核心市场应尽早改为直接申请。

五、不同市场的程序差异

市场驳回后的主要路径大致周期
美国(USPTO)驳回复审(Office Action Response),可主张共存3–6 个月
欧盟(EUIPO)复审(BoA 上诉),可请求共存或限制商品6–12 个月
中国(CNIPA)驳回复审,配合撤三/无效清除在先障碍9–12 个月
香港驳回复审 + 异议,程序相对紧凑6–12 个月

同样的驳回理由,在不同市场的成功率与周期差别很大。跨境布局时,建议先处理"核心销售市场"的障碍,再按预算推进其他市场。

六、注册前的四件事

  1. 做检索:目标市场的在先商标、近似商标与类别覆盖
  2. 选标识:优先臆造词/任意词,避免描述性与通用词
  3. 定类别:核心类别 + 关联类别,不要只注册"现在卖的"
  4. 选路径:核心市场逐国申请,非核心市场可用马德里分摊成本

常见问题

被驳回后官费能退吗?

通常不退。官费对应审查程序已经发生,驳回后需要重新申请或进入复审并另行缴费。

复审成功率有多高?

取决于驳回理由与证据。相对理由中,若能证明市场区分、取得共存同意或清除在先障碍,成功率会明显提高;绝对理由的复审难度较大。

被抢注一定要打官司吗?

不一定。可以先评估异议、无效、撤三与协商转让的成本与周期,选择最快能让产品合规上市的组合。

马德里注册和逐国注册怎么选?

核心市场建议逐国直接申请(不受基础申请影响);非核心或预算有限的市场可用马德里分摊成本,但要接受"中心打击"风险。
